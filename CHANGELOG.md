# Changelog

All notable changes to this project are documented here.

## Unreleased

## 0.1.0-alpha.0 - 2026-09-19

### Added

- Durable operation domain, SQLite stores, execution/retry/recovery and UNKNOWN verification.
- Expo reliability laboratory with local fixture and end-to-end response-loss verification.
- Read-only development inspector for durable Operations, including redacted payloads and timelines.
- Docusaurus documentation site and GitHub Pages deployment workflow.

### Changed

- Simplified the reliability lab into Run and Inspector tabs with a focused operation-detail view.
- Added SonarQube, Semgrep Community and dependency-audit gates to the pull-request workflow.
